# SyncBank Operations Desk

## Direction

Una mesa de control financiera sobria: superficies claras cálidas, navegación azul petróleo, tipografía precisa y color semántico reservado para estados y acciones.

## Typography

- Manrope para títulos y cifras operativas.
- DM Sans para navegación, tablas, formularios y texto funcional.

## Color

- Fondo marfil frío y paneles blancos para lectura prolongada.
- Azul petróleo como estructura y verde como acción principal.
- Ámbar, rojo y azul únicamente para estados semánticos.

## Components

- Radio de 9–14 px; las píldoras se reservan para estados compactos.
- La profundidad se expresa con sombras suaves, sin combinar borde y sombra en tarjetas.
- Tablas densas, cifras tabulares y controles con foco visible.
- Skeletons durante consultas; errores nombran problema y recuperación.

## Motion

- Entrada escalonada de cada vista con desenfoque y desplazamiento sutil.
- Interacciones entre 140 y 220 ms.
- Toasts con entrada lateral y popovers con escala suave.
- `prefers-reduced-motion` elimina movimiento no esencial.
